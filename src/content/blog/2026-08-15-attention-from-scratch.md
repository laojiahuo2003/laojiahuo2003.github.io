看了很久的"Attention is All You Need"，能背公式，但合上纸就说不出 Q、K、V 到底是什么。这篇笔记把我卡了三天的地方和最后的理解记下来，最后附一个自己写的 20 行 numpy 实现——**能自己写出来，才算真的懂了**。

## 一句话版本

注意力回答的问题是：**这个词应该"关注"上下文里的哪些词？**

每个 token 的输出，是上下文所有词的信息加权和——权重就是"注意力分数"。

## Q、K、V 到底哪来的

我卡住的真正原因是：以为 Q、K、V 是模型的三组输入。**错。它们是同一个输入的三次变换**。

每个 token 的词向量 x（维度 d），乘三张不同的矩阵，得到三个角色：

- **Q**（Query，查询）：我想找什么信息？
- **K**（Key，键）：我这里有什么信息？
- **V**（Value，值）：我实际能提供的内容是什么。

用检索系统类比：Q 是搜索框里打的词，K 是每个网页的标题/标签，V 是网页正文。搜索词和标题做匹配（Q·K 算相似度），匹配度决定正文被引用多少（加权求和 V）。

关键在于：**匹配的依据（Q·K）和提供的内容（V）是解耦的**。这个解耦让"相关性"和"内容"可以被独立学习——这是整个结构里最聪明的一步。

## 公式逐块拆

```text
Attention(Q, K, V) = softmax(QKᵀ / √d_k) V
```

- **QKᵀ**：每个 Q 和每个 K 点积 → 相似度矩阵（行=query 位置，列=key 位置）；
- **除以 √d_k**：我原来以为是个 trick，其实是个必要保护。向量维度越高，点积的数值天然越大（d 个乘积求和），大数值进 softmax 会变成接近 one-hot 的尖锐分布，梯度消失。除回 √d 把方差稳定在 1 附近；
- **softmax**：把分数变成每行和为 1 的权重；
- **乘 V**：按权重把所有 value 混起来，得到这个位置的新表示。

## 因果掩码：未来的词不许看

生成式模型训练时，第 i 个 token 不能看见第 j>i 个 token（否则就是抄答案）。做法很朴素：QKᵀ 算完之后，把对角线以上的位置填成 −∞，softmax 后这些位置自然变成 0。

推理时这就是 KV Cache 的边界：**已有 token 的 K、V 不变，所以缓存**——正是[上一篇 KV Cache 笔记](/blog/2026-08-15-kv-cache-notes/)的起点。

## 多头：一个注意力不够用

一个头只能学一种关注模式（指代、语法、位置……远远不够）。多头注意力把 d 维切成 h 份，每份独立做一遍注意力（各自有自己的 W_Q/W_K/W_V），结果拼回来。

代价是每头的维度变成 d/h，总计算量基本不变——**用同样的钱买了多个视角**。这个"分组"的思路后面一路演化出 MQA、GQA、MLA（我正在写的下一篇）。

## 20 行 numpy 实现

```python
import numpy as np

def softmax(x):
    e = np.exp(x - x.max(-1, keepdims=True))   # 减最大值防溢出
    return e / e.sum(-1, keepdims=True)

def attention(x, Wq, Wk, Wv):
    """x: (T, d) 一串 token；W*: (d, d) """
    Q, K, V = x @ Wq, x @ Wk, x @ Wv           # 1. 三个角色
    T = x.shape[0]
    scores = Q @ K.T / np.sqrt(Q.shape[-1])    # 2. 相似度 + 缩放
    mask = np.triu(np.ones((T, T)), k=1)       # 3. 上三角=未来
    scores = np.where(mask, -np.inf, scores)   #    未来不许看
    return softmax(scores) @ V                 # 4. 加权混合 V
```

随机初始化跑通后我做了两个小实验，比读十篇教程都有用：

1. 把 mask 去掉重新跑——每个位置立刻"看见未来"，输出全变。因果性就藏在这一个 `np.where` 里；
2. 手工构造两个强相关的 token，看注意力矩阵那两格亮起来——"权重"从抽象概念变成了能看见的数字。

## 卡了三天的原因，最后总结成一句

我一直在找"Q、K、V 的物理意义"，但它们没有先验的物理意义——**它们是三个可学习的投影，模型自己决定拿它们表示什么**。类比（搜索、图书馆）只是脚手架，真正的意义是训练出来的。想通这一点的那天，公式就不用背了。
