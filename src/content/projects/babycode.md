- 基于 Python 标准库构建零依赖终端 AI 编程助手，实现多轮工具调用与自动规划执行的 Agent Loop，集成三层记忆架构、智能上下文压缩、30+ 内置工具与 MCP 协议扩展，支持细粒度权限管理与会话持久化，测试覆盖率 98.9%，跨平台部署
- 零依赖架构：完全基于 Python 标准库实现，通过自研 ANSI TUI 引擎、对象池、LRU 缓存等技术，安装包体积 < 1MB，支持 Windows / macOS / Linux 跨平台运行
- Agent Loop 与权限系统：设计隐式状态机实现多轮工具调用的自动规划执行，通过 progress 与 final 标签区分中间进度与最终答案，支持进度消息自动 nudge、空响应重试、max_tokens 恢复等边界处理；构建跨线程同步的交互式权限审批系统，支持路径访问、命令执行、文件编辑三类权限的 7 种决策类型及持久化存储
- 三层记忆系统：设计 USER / PROJECT / LOCAL 三层记忆架构，实现跨会话知识持久化；实现基于优先级和访问时间的自动压缩算法（95% 阈值触发），有效解决长对话上下文溢出问题
- 性能优化：针对中英文混合场景设计基于正则表达式的快速 Token 估算算法，性能从 35 ops/sec 提升至 285 ops/sec；通过 5 轮系统化优化，CPU 空闲使用率降低 60%，GC 压力降低 30-50%
