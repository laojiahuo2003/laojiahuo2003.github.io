- 辅助大学生学习的 AI 平台，支持 AI 交互、资料库、用户在线交流等模块，提供个性化学习支持与服务；已注册为亚马逊云创计划项目和 AI 数智大会孵化项目，上线日活 1065 人、注册 3298 人（含内测）
- 借鉴 RBAC 思想实现用户会员权限系统，利用 SpEL 表达式对不同会员等级采取不同的限流策略
- 利用自定义注解和 AOP 封装请求响应加解密 starter，实现接口传入参数自动解密、返回参数自动加密
- 基于 Netty 实现 WebSocket 协议，采用心跳机制确保用户连接稳定，实现即时通讯 IM 与实时在线讨论习题模块
- 使用策略模式将不同 LLM 大模型处理逻辑封装成独立策略类，支持灵活的对话场景切换，提高系统扩展性与可维护性
- 基于 Elasticsearch 的向量化数据库实现数学大模型 RAG 知识库的高效相似性搜索，提升智能推理和问题解答能力
- 实现简单的布隆过滤器用于缓存层，缓解缓存穿透问题，避免不必要的数据库查询
- 使用 Bitmap 实现签到补签功能，结合 Redis 缓存加速签到查询，支持高效的积分统计与查询
- 设计日活统计模块，利用 HyperLogLog 代替 Redis Set 存储网站 UV，减少内存消耗
