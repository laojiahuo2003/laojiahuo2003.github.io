补充素材（本轮新查到、值得进正文的）：
- **U-统计量视角**（arXiv 2603.01162，2026-03）：GRPO 的策略梯度本质是**二阶 U-统计量**，核为成对差 $\frac{1}{2}[\nabla\log\pi(Y^{(i)})-\nabla\log\pi(Y^{(j)})](Z^{(i)}-Z^{(j)})$；Hoeffding 分解后一阶项 = oracle（带真值 value 函数）的 MSE，残差 $O(G^{-2})$。由此得**普适缩放律**：次优性上界 $=\frac{c_1}{B}+\frac{c_2}{BG}+\frac{c_3}{BG^2}$，最优组大小 $G^*=\sqrt{c_3/c_1}$，**与预算、迭代数、学习率调度无关**。
- **GSPO 的序列级比率**：$s_i(\theta)=\big(\pi_\theta(o_i|q)/\pi_{old}(o_i|q)\big)^{1/|o_i|}$，整段序列共享一个比率 → 裁剪裁掉的是**整个序列**而非个别 token；归一化防止长序列比率爆炸；解决 MoE 专家切换带来的结构性方差。Qwen3 采用。
- **DAPO 的 token 级 loss**：$\frac{1}{\sum_i|o_i|}\sum_i\sum_t$ 取代 $\frac{1}{G}\sum_i\frac{1}{|o_i|}\sum_t$；200-token 与 10-token 两个回答，前者每 token 权重 $(1/200)(1/2)$、后者 $(1/10)(1/2)$ —— 长度稀释的算例很好用。
- **DPO 失效的根源**：偏好确定性时（$P(y_w\succ y_l)=1$），BT 的 MLE 要求 $\Delta\to\infty$，此时**KL 正则完全失效**，无论 $\beta$ 多大最优解都是把 $y_l$ 压到 0 —— 这是过拟合的机理，不是调参问题。

## 二、共性骨架（几乎都走这条路）

1. 从 RLHF 的三阶段（SFT → RM → RL）讲起
2. 给出 KL 正则目标 $\max \mathbb{E}[r]-\beta D_{KL}$
3. PPO：clip 目标 + 四个模型的显存痛点
4. DPO：闭式解 → 分类损失，省掉 RM 与在线采样
5. GRPO：组内均值当 baseline，省掉 critic
6. 对比表 + 选型建议

## 三、全网都没做好的（差异化空间）

1. **"三次减法"的统一叙事缺位**：大家都按「PPO 篇 / DPO 篇 / GRPO 篇」分开写，没人用一条主线把三者串成"同一个目标函数的三种解法，每次减掉一样东西"。本博 SwiGLU 篇的「演进史 + 一句话结论」结构正好适配。
2. **clip 的四象限表**：多数文章只说"clip 限制更新幅度"，没人把 $A>0/A<0$ × $r>1+\varepsilon/r<1-\varepsilon$ 四种情况列全，讲清"单边惩罚"。这是 PPO 最容易讲错的地方。
3. **std 归一化的双重偏差**：Dr.GRPO 那节普遍被略过或讲错。**注意别讲错**：$\sigma=0$（全对/全错）时分子 $r_i-\mu$ 也恰好为 0，`+1e-4` 兜底后 $A=0$，**这是安全的，不是「放大成 1e4」**（本会话已用 verify 脚本核实）。真正的偏差在 $\sigma$ 极小但不为 0 时：`rewards=[1,1,1,0.999]` → $\mu=0.99975,\sigma\approx4.33\times10^{-4}$ → $A\approx[+0.469,+0.469,+0.469,-1.407]$，**原始分差仅 $10^{-3}$ 却被抬到和中等难度题（$\pm1$）相当的权重** —— 即归一化抹平了「题目信息量」这个维度，**模型被推向已经会做或根本做不会的题**。这个反直觉结论是全文最值钱的一段。
4. **$G^*=\sqrt{c_3/c_1}$ 的普适性**：2026 年的新结果，中文博客几乎没人写。"最优组大小与算力预算无关"是很强的实践结论。
5. **奖励范式转变 > 算法改进**：GRPO 能成不是因为算法多妙，而是 RLVR 找到了不可 hack 的奖励。这条判断力比任何公式都重要，且是"先问奖励、再问算法"的通用方法论。
6. **显存/超参的实账**：四个模型 vs 两个模型 vs 两个模型（ref+policy），DPO 的 lr 要比 SFT 小一个量级（5e-7~5e-6），这些工程细节分散在各处，没人汇总成一张卡。

用户要求"写几个版本，我选最喜欢的"。四个版本按**读者门槛**和**用途**分档，不是同一篇的删减：
